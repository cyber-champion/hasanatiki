Проверка и сборка Хасанатиков

GitHub main — актуальный исходник приложения. index.html, sw.js и
offline-pack.json публикуются вместе. Конфигурация сайта и учебные файлы
остаются на месте.

Из корня полной копии репозитория:
  node tools/verify-release.cjs
  node tools/verify-release.cjs --stage dist

Команда работает на Node 22 без дополнительных пакетов. Она проверяет
встроенный JavaScript, границы разметки таджвида, список аятов обоих
чтецов и наличие ресурсов. --metadata-only проверяет исходники и списки
в локальной копии, где может не быть всех MP3.

Корневой сайт по-прежнему выпускает существующий GitHub Pages. Проверка
GitHub Actions показывает результат для main и pull requests. Перед
обновлением main запустите тот же скрипт для проверяемой сборки.

SQL migrations применяются в Supabase перед публикацией. Закрытый банк
дуэлей загружается отдельно и не включается в папку сайта.
