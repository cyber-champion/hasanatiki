РЕЙТИНГ МЕДРЕСЕ — КАК ЗАПУСТИТЬ (≈20 минут)
==========================================

Что внутри архива
  index.html            — само приложение
  config.js             — настройки: название, адрес базы (правите только его)
  setup.sql             — создаёт базу данных (запускается один раз)
  manifest.webmanifest, icon-*.png, apple-touch-icon.png — значок на телефоне
  _headers              — настройки безопасности для Netlify

ШАГ 1. База данных (Supabase, бесплатно)
  1. Зайдите на supabase.com → Start your project → войдите через почту или GitHub.
  2. New project. Имя любое, например madrasa. Регион: Central EU (Frankfurt) — ближе всего к России.
     Пароль базы придумайте и сохраните (он нужен редко).
  3. Слева: SQL Editor → New query. Откройте setup.sql в Блокноте, скопируйте ВСЁ,
     вставьте и нажмите Run. Должно появиться «Success».
  4. Слева: Project Settings → API (или «API Keys»). Скопируйте:
       • Project URL — вида https://abcd1234.supabase.co
       • publishable key (или «anon public») — длинная строка.
     Секретный ключ (service_role / secret) никуда не вставляйте.

ШАГ 2. Настройки
  Откройте config.js в Блокноте и впишите:
       name: "Хасанатики",
       supabaseUrl: "https://abcd1234.supabase.co",
       supabaseKey: "скопированный publishable key"
  Сохраните.

ШАГ 3. Сайт (Netlify, бесплатно)
  1. Зарегистрируйтесь на netlify.com.
  2. Sites → Add new site → Deploy manually → перетащите ПАПКУ madrasa-rating целиком.
  3. Через минуту будет адрес вида https://что-то.netlify.app. В Site settings → Change site name
     можно сделать понятнее, например medrese-mozhga.netlify.app.
  Позже можно подключить свой домен или перенести папку на российский хостинг — это обычные файлы.

ШАГ 4. Первый запуск
  1. Откройте адрес сайта. Появится «Первый запуск» — создайте свой аккаунт администратора.
  2. Кабинет → «Новая группа». Код группы придумается сам.
  3. «Добавить учителя» → имя, логин, пароль, отметьте его группы. Передайте учителю логин и пароль.
  4. «📋 Ссылка» у группы — отправьте её в чат родителей и детей. Входить им не нужно.

ПЕРЕНОС ИЗ СТАРЫХ САВАБИКОВ
  В старом приложении: Учитель → Скачать копию. В новом: откройте группу → Учитель →
  Восстановить из файла. Ученики, баллы, суры и Зал славы перенесутся, аватарки заменятся на новые.

ЧТО ВАЖНО ЗНАТЬ
  • Проверьте сайт с телефона БЕЗ VPN: и сам сайт, и сохранение баллов.
  • Бесплатный проект Supabase засыпает, если им долго не пользуются. Тогда зайдите на supabase.com
    и нажмите Restore — данные не пропадут.
  • Раз в сезон скачивайте копию каждой группы (Учитель → Скачать копию).
  • Обновить приложение: замените index.html на новый (config.js оставьте свой) и снова перетащите
    папку в Netlify (Deploys → перетащить).
  • Если код группы попал к чужим — Кабинет → ✏️ у группы → «Новый код».
